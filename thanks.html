Getting started

  1. 1 · Download and unzip

    Click the button above and unzip the file you get. Keep the unzipped folder somewhere you'll keep it — that folder is the app.

  2. 2 · You need Python 3.10 or newer

    It's free from python.org, and it's the only thing the core tool needs. Recording and transcription use two optional extra packages — one install command, listed in the README inside the folder — plus the free ffmpeg program if you'll transcribe non-WAV recordings.

  3. 3 · Try it on the samples first

    Open a terminal (Mac/Linux) or Command Prompt (Windows) in the unzipped folder and run:
    python -m meetscribe import samples
    python -m meetscribe actions
    That loads the four sample meetings and shows you the action items and decisions. To use the point-and-click view instead, run python -m meetscribe serve and open http://127.0.0.1:8765 in your browser.

  4. 4 · Your license key

    Your key is emailed to the address you paid with. It removes the trial limit — until it arrives, the app works as a free trial for your first 5 meetings, so you can start right away. Activate it with:
    python -m meetscribe license activate MSCR-.... --email you@example.com
    Bought Pro? Your Pro key comes in the same email — activate it with python -m meetscribe license activate-pro MSPR-.... --email you@example.com.
